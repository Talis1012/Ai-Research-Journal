# Research Journal AI — UI mockup brief

These mockups reorganize the existing Streamlit application into four primary pages while preserving its current visual language.

## Shared visual system

- Desktop research application, 16:10 canvas, high-fidelity product UI.
- White background and panels; thin `#DFE6EF` dividers; very subtle `rgba(16,24,40,.055)` shadows.
- Inter-style sans-serif typography; dark navy `#101828`; muted gray `#667085`.
- Primary blue `#1769D2`, cyan/teal `#1492BC`; pale-blue active navigation `#EAF3FF`.
- 7–9 px corner radii, compact spacing, restrained scientific aesthetic.
- Persistent top bar: molecular node logo, “Research Journal AI”, project selector, global search, help, notifications, user profile.
- Persistent left navigation with four primary destinations: Experiments, Library, Data Analysis, Paper Writing.
- Use realistic content from the CM-01 medicinal chemistry project.

## Deliverables

1. `experiments-workspace.png` — Experiments page, Workspace sub-tab selected. Experiment browser, Notes/AI Chat area, audio transcription, experiment metadata and recent activity.
2. `experiments-insights.png` — Experiments page, Insights sub-tab selected. AI summaries, key ideas, cross-experiment comparison and interactive mind map.
3. `library-my-library.png` — Library page, My Library sub-tab selected. Folder tree, filters, paper table/cards, tags and file management.
4. `library-discover.png` — Library page, Discover sub-tab selected. Scientific search, AI-generated queries, results, AI discussion and “Add to My Library” actions.
5. `paper-writing.png` — Paper Writing page. Outline, manuscript editor, sources/citations and a contextual AI assistant side panel.
6. `data-analysis-v2.png` — Data Analysis page. Dataset source, preview, scikit-learn workflow setup, metrics, interactive chart concepts and exports.

## Shared constraints for image generation

- Render as a straight-on product screenshot, not a device mockup and not concept art.
- Practical, implementable Streamlit-style desktop layout.
- Crisp readable typography, no perspective, no gradients except the existing subtle cyan primary button treatment.
- No external logos, no watermark, no decorative laboratory photography.
- Keep the four primary navigation destinations and each page’s sub-tab row clearly visible.
